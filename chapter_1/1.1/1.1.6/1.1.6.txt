- Conditional Expressions and Predicates

Case analysis, in Lisp it is called cond, which stands for "conditional"
and is used as follows:

(define (abs x)
  (cond ((> x 0) x)
        ((= x 0) 0)
        ((< x 0) (- x))))


- the general form is:
(cond (<p1> <e1>)
      (<p2> <e2>)
      ...
      (<pn> <en>))

consisting of the symbol cond followed by parenthesized paris of expressions
(<p> <e>)
called clauses.
The first expression in each pair is a predicate- that is, an expression whose value is
interpreted as either true or false.


- Another way to write the absolute-value procedure is:

(define (abs x)
  (cond ((< x 0) (- x))
        (else x)))

which could be expressed in Engilsh as "If x is less than zero return -x; otherwise return x".
The else returns x.


- Yet Another way to write the absolute-value procedure:

(define (abs x)
  (if (< x 0)
      (- x)
      x))

This uses the special for if, a restricted type of conditional that can be used when there are
precisely two cases in the case analysis. The general form of an if expression is:

(if <predicate> <consequent> <alternative>)
